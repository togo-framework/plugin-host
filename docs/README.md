# plugin-host — docs

Database-driven runtime plugin registry for togo (the sentra-style plugins
table): host, enable/disable, and configure plugins live, and compose
capabilities over the workflow plugin.

- **Install:** `togo install togo-framework/plugin-host`
- **Marketplace:** https://to-go.dev/plugins/plugin-host
- **Source:** https://github.com/togo-framework/plugin-host

See [usage.md](usage.md) for the plugins model, runtime toggling, capabilities,
and workflow-step composition.
